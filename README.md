# AI Coding Standards

> 面向 AI 编程助手的编码规范，覆盖通用与 C++ 两大场景，可直接集成到 Trae / Cursor / Copilot 等工具的规则上下文中。

**仓库描述**：面向 AI 编程助手的编码规范，含通用规则与 C++ 专用规则，支持反模式清单、关键词索引与正反例，可直接集成到 AI 工具规则上下文。

---

## 为什么需要这个项目

AI 编程助手在编码时存在三大痛点：

1. **规则分散**：传统编码规范面向人类，AI 难以一次性加载并遵循
2. **边界模糊**：抽象原则（如 KISS）缺乏正反例，AI 不知如何落地
3. **易犯错误**：AI 会顺手重构无关代码、捕获过宽异常、使用保留标识符等

本项目通过**元信息声明、反模式清单、关键词索引、正反例**四重机制，让 AI 在编码前即可获得完整的决策框架。

## 仓库结构

```
.
├── AI编码规范(通用).md      # 通用规则（Python/JS/TS/Go/Java/Rust/C# 等）
├── AI编码规范(C:C++).md     # C++ 专用规则（通用规则的细化与覆盖）
└── README.md
```

### 两份规范的关系

- **通用版**：适用于所有编程语言的基础规则
- **C++ 版**：在通用版基础上细化的 C++ 专用规则
- **冲突裁决**：C++ 版优先于通用版；两者冲突时以 C++ 版为准

## 规范特点

| 特性 | 说明 |
|------|------|
| 元信息声明 | 文档头部明确适用范围、使用方式、优先级、与其他规范关系 |
| AI 反模式清单 | 集中列出 13~15 条 AI 高频错误，便于一眼扫描避坑 |
| 关键词速查索引 | 附录提供关键词→章节映射表，提升检索效率 |
| 正反例对照 | 为易错规则（列表初始化、智能指针、异常捕获等）提供代码示例 |
| 语义化版本 | 遵循 SemVer，便于追踪规范演进 |
| 最小变更原则 | 明确 AI 修改老代码时不强制重构未触及部分 |

## 快速使用

### 方式一：作为 AI 工具规则上下文

将对应规范文件内容粘贴或引用到 AI 工具的规则配置中：

- **Trae IDE**：放入项目根目录，或配置为 user rules / project rules
- **Cursor**：放入 `.cursor/rules/` 目录
- **GitHub Copilot**：放入 `.github/copilot-instructions.md`

### 方式二：作为团队编码规范

直接作为团队的编码规范文档分发，新成员入职时阅读遵循。

### 方式三：作为代码审查依据

在 PR/MR 模板中引用规范章节号（如"本 PR 遵循 C++ 版 7.1 列表初始化规则"）。
